# 中英文单词消消乐 🎮

一个有趣的教育类网页游戏,帮助玩家学习中英文单词配对。

## 📁 项目结构

```
中英文单词消消乐/
├── index.html              # 主页面
├── README.md               # 项目说明
├── css/
│   └── styles.css          # 样式文件
├── js/
│   ├── words-data.js       # 单词数据模块
│   ├── audio-generator.js  # 音效生成模块
│   ├── game-logic.js       # 游戏逻辑模块
│   └── ui-controller.js    # UI控制模块
└── audio/                  # 音效文件夹(预留)
```

## 🎯 游戏特性

### 核心玩法
- **配对机制**: 点击中文单词和对应的英文单词进行配对
- **计分系统**: 配对成功得10分
- **时间奖励**: 通关后获得时间奖励(剩余秒数×2)
- **限时挑战**: 60秒内完成8对单词配对

### 音效系统
- ✅ **匹配成功音效**: 愉悦的上扬音调(使用Web Audio API生成)
- ✅ **匹配失败音效**: 低沉的下降音调(使用Web Audio API生成)
- 无需外部音频文件,自动生成

### 游戏控制
- **开始游戏**: 初始化并开始新一局游戏
- **重新开始**: 直接重开一局(无需清空界面)
- **再来一局**: 结算弹窗中点击直接重开

### 视觉效果
- ✨ 渐变紫色背景
- 🎨 毛玻璃效果信息面板
- 🎭 卡片悬停和点击动画

## 🚀 如何运行

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器:
   ```bash
   # 使用Python
   python -m http.server 8000

   # 使用Node.js (需要先安装 http-server)
   npx http-server
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 🎮 操作说明

1. 点击 **"开始游戏"** 按钮开始
2. 点击一个中文单词卡片
3. 点击对应的英文单词卡片
4. 配对成功: 播放愉悦音效,卡片消失,获得10分
5. 配对失败: 播放低沉音效,卡片震动提示
6. 消除所有卡片或时间结束即游戏结束
7. 点击 **"重新开始"** 可随时重开一局

## 🔧 技术架构

### 模块化设计
- **words-data.js**: 单词库数据和工具函数
- **audio-generator.js**: 音效生成器(使用Web Audio API)
- **game-logic.js**: 游戏核心逻辑类 `WordMatchGame`
- **ui-controller.js**: UI控制类 `UIController`

### 主要类和方法

#### WordMatchGame (游戏逻辑)
- `init()`: 初始化游戏
- `selectCard()`: 选择卡片
- `checkMatch()`: 检查配对
- `handleMatch()`: 处理匹配成功(使用回调通知完成)
- `handleMismatch()`: 处理匹配失败
- `startTimer()`: 启动计时器
- `calculateFinalScore()`: 计算最终得分

#### UIController (界面控制)
- `startGame()`: 开始游戏
- `renderGame()`: 渲染游戏界面
- `handleCardClick()`: 处理卡片点击
- `playSound()`: 播放音效
- `endGame()`: 结束游戏并显示结果

#### AudioGenerator (音效生成)
- `init()`: 初始化AudioContext
- `playMatchSound()`: 生成匹配成功音效
- `playWrongSound()`: 生成匹配失败音效
