# 知识关系图谱

一个基于物理引擎的交互式知识图谱可视化工具，帮助你以树状结构组织和探索知识节点之间的关系。

## 功能特性

- **物理仿真**: 基于弹簧-质点模型的物理引擎，节点移动自然流畅
- **可视化关系**: 以树状结构展示知识节点之间的父子关系
- **交互操作**: 支持拖拽节点、缩放视图、搜索过滤
- **编辑模式**: 可自由创建、编辑、删除节点和调整关系
- **本地存储**: 数据保存在浏览器本地存储中，刷新不丢失

## 快速开始

### 基本操作

1. **创建节点**
   - 点击屏幕中央的 `+` 按钮
   - 输入节点标题和内容
   - 可选择父节点建立层级关系
   - 点击"创建"完成

2. **查看内容**
   - 鼠标悬停在节点上可高亮显示其连接关系
   - 单击节点查看详细内容

3. **拖拽节点**
   - 直接拖动任意节点，整棵树会弹性跟随移动
   - 物理引擎自动处理节点间的弹簧拉扯效果

4. **缩放和平移**
   - 使用鼠标滚轮缩放视图
   - 按住鼠标左键拖动画布进行平移
   - 点击右上角 `⟲` 按钮重置视图

## 编辑模式

编辑模式允许你自由调整节点之间的父子关系。

### 启用编辑模式
- 点击右上角的 `✎` 按钮进入编辑模式（按钮变为红色）

### 编辑节点
1. 双击任意节点打开编辑面板
2. 修改节点标题、内容或标签
3. 调整父节点关系
4. 点击"保存"或"删除"

### 调整关系（拖拽连接）
1. 进入编辑模式
2. 拖动一个节点靠近另一个节点
3. 当两个节点接触时自动建立父子关系
4. 被拖动的节点会成为目标节点的子节点

**注意**:
- 拖动开始时会自动断开原有的父节点连接
- 系统会自动检测并防止循环引用

## 搜索功能

- 使用顶部搜索框输入关键词
- 匹配的节点会保持高亮，其他节点和连线会变淡
- 支持标题和标签搜索

## 控制按钮

| 按钮 | 功能 |
|------|------|
| ✎ | 切换编辑模式 |
| + | 放大视图 |
| − | 缩小视图 |
| ⟲ | 重置视图到初始状态 |

## 物理引擎参数

系统采用基于物理的自动布局，包含以下力场：

- **弹簧力**: 父子节点之间的弹性连接，目标长度 100px
- **排斥力**: 节点之间的相互排斥，避免重叠
- **引力井**: 距离中心越远吸引力越强，防止节点飘离视野

## 数据管理

### 保存
数据自动保存到浏览器本地存储（localStorage），每次操作后自动保存。

### 清除数据
访问 `clear-storage.html` 页面可清除所有存储的节点数据。

## 技术栈

- 纯 HTML/CSS/JavaScript 实现
- SVG 绘制连接线
- requestAnimationFrame 实现流畅动画
- 无外部依赖库

## 浏览器兼容

支持所有现代浏览器：
- Chrome/Edge (推荐)
- Firefox
- Safari

## 使用场景

- **知识管理**: 构建个人知识体系
- **思维导图**: 可视化思维过程
- **项目规划**: 展示任务依赖关系
- **学习笔记**: 整理概念间的关联

## 提示

- 拖动节点时，其他节点会变淡以便聚焦
- 鼠标悬停节点时，相关连接线会高亮显示
- 编辑模式下可随意调整结构，退出后自动保存
- 物理引擎会持续运行，使节点保持自然分布

## 开发者

如需自定义物理参数，可修改 `js/app.js` 中的 `config` 对象：

```javascript
this.config = {
    minDistance: 100,       // 节点间最小距离
    repulsionStrength: 0.4, // 排斥力度
    connectionDistance: 100, // 连接线目标长度
    damping: 0.88,          // 阻尼系数
    springStrength: 0.08,   // 弹簧强度
    // ...
};
```
