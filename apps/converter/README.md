# 多国货币转换器 💱

一个功能强大、界面精美的实时货币汇率转换工具，支持多种世界货币的实时转换和汇率查询。

## 功能特点

### 核心功能
- **实时汇率转换** - 支持全球 30+ 主流货币的实时转换
- **汇率速查表** - 快速查看常用货币对汇率
- **智能货币识别** - 自动识别货币代码和符号
- **双向转换** - 一键交换源货币和目标货币

### 实用工具
- **收藏功能** - 保存常用的货币转换组合
- **历史记录** - 自动记录转换历史，方便追溯
- **一键复制** - 快速复制转换结果
- **汇率更新时间** - 显示汇率最后更新时间

### 用户体验
- **响应式设计** - 完美适配桌面、平板和移动设备
- **深色/浅色主题** - 支持主题切换，保护视力
- **离线缓存** - 缓存常用汇率数据，离线也能查询
- **优雅动画** - 流畅的过渡动画和交互反馈

## 技术栈

- **HTML5** - 语义化标签，SEO友好
- **CSS3** - 现代化样式，CSS Grid 和 Flexbox 布局
- **JavaScript (ES6+)** - 模块化开发，原生 JS 实现
- **LocalStorage API** - 本地数据持久化
- **Fetch API** - 异步数据请求

## 快速开始

### 在线使用
直接在浏览器中打开 `index.html` 文件即可使用。

### 本地运行
1. 克隆或下载本项目
2. 用浏览器打开 `index.html`
3. 开始转换货币！

### API 配置
项目使用免费的汇率 API，如需更换 API：

编辑 `js/api.js` 文件：
```javascript
const API_CONFIG = {
    baseUrl: 'your-api-endpoint',
    apiKey: 'your-api-key'
};
```

## 使用说明

### 基本转换
1. 选择"从"货币和"到"货币
2. 输入要转换的金额
3. 点击"转换"按钮查看结果

### 收藏功能
点击"收藏"按钮保存当前货币组合，方便快速访问。

### 查看历史
在历史记录区域查看最近的转换记录。
