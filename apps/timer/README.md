# 🍅 番茄计时器

一个功能完整的番茄计时器网页应用，采用经典的番茄工作法（Pomodoro Technique），帮助你提高工作效率。

![番茄计时器](https://img.shields.io/badge/version-1.0.0-brightgreen) ![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ 功能特点

### ⏱️ 核心功能
- **番茄钟计时**：默认25分钟工作时段
- **短休息**：默认5分钟休息
- **长休息**：默认15分钟（每完成4个番茄钟后）
- **暂停/继续**：随时暂停和恢复计时
- **重置功能**：一键重置当前计时
- **跳过功能**：跳过当前时段进入下一个

### 🎨 可视化功能
- **圆形进度条**：直观显示剩余时间
- **动态标题**：浏览器标签页显示倒计时
- **状态指示**：清晰显示当前模式（工作/短休息/长休息）
- **视觉提醒**：计时结束时页面闪烁效果

### 📊 统计功能
- **今日统计**：今天完成的番茄钟数量和专注时长
- **累计统计**：总共完成的番茄钟数
- **数据持久化**：刷新页面数据不丢失

### ⚙️ 自定义设置
- **时间调整**：自由设置工作/短休息/长休息时长
- **自动开始**：休息后自动开始下一个番茄钟
- **音效控制**：开关和音量调节
- **主题选择**：5种精美主题可选
- **数据管理**：清除所有数据

### 🔔 提醒功能
- **声音提醒**：使用Web Audio API生成悦耳提示音
- **桌面通知**：浏览器原生桌面通知
- **视觉提醒**：页面边缘闪烁动画

### 📝 任务管理
- **添加任务**：创建待办任务列表
- **完成任务**：标记任务完成状态
- **番茄钟绑定**：为任务添加已完成的番茄钟
- **删除任务**：移除不需要的任务
- **任务统计**：显示每个任务的番茄钟数量

## 🎯 使用方法

### 1. 打开应用
直接在浏览器中打开 `index.html` 文件即可使用。

### 2. 开始番茄钟
点击"开始"按钮开始25分钟的工作计时，或者使用空格键快速启动。

### 3. 休息时间
工作完成后，会自动进入休息模式：
- **短休息**：5分钟（默认）
- **长休息**：15分钟（每4个番茄钟后）

### 4. 管理任务
- 在任务列表中输入任务名称，点击"添加"
- 点击任务旁的"+"按钮添加番茄钟
- 勾选复选框标记任务完成

### 5. 自定义设置
点击右上角设置图标，可以：
- 调整各模式时长
- 开关自动开始
- 调节音量和音效
- 切换主题颜色
- 清除所有数据

## 📝 开发说明

直接打开 `index.html` 即可运行，无需服务器。

### 模块说明
- `config.js` - 应用配置和状态管理
- `storage.js` - LocalStorage数据操作
- `audio.js` - Web Audio API音效生成
- `timer.js` - 计时器核心逻辑

所有数据保存在浏览器的 LocalStorage 中：
- `pomodoro_settings` - 用户设置
- `pomodoro_stats` - 统计数据
- `pomodoro_tasks` - 任务列表
- `pomodoro_today_date` - 日期记录

## 🎯 番茄工作法说明

番茄工作法是一种时间管理方法：
1. 选择一个任务
2. 设置25分钟计时器
3. 专注工作直到计时器响起
4. 短暂休息5分钟
5. 每完成4个番茄钟，休息15-20分钟
